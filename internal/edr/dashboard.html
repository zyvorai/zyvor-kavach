    Provenance
    
        
    Follow a suspicious chain, with its gaps in view.
    
        
    Findings grouped into ranked stories over a process graph built from polled telemetry. It is a lead for investigation, not a verdict, and it observes only.
    
      
    
      
    
        Limitations (always apply)
        
    • This is a process-lifetime graph rebuilt from polled process, network and file telemetry. It is not a kernel audit graph.
    • Most file events carry no writing process, so file activity is largely absent. Polling can miss short-lived processes, so chains can have gaps.
    
      
    
      
    
      
    
        
        
        
        
        
      
    
      
    
      
    
        
    Story
    
        
    
      
    
      
    What the graph includes and lacks
    
      
    
    
    
    

    
    
    
      
    
        
    Ransomware behaviour
    
        
    File-activity patterns that look like mass encryption.
    
        
    A per-host score over sliding windows of file events. It reports and ranks; it never blocks, kills or quarantines. The separate Ransomware page is the early-warning view.
    
      
    
      
    
        This detector cannot see (always apply)
        
    • It sees only file path, size and event rate. It cannot see file contents and cannot see which process did the writing.
    • It has known evasions: slow encryption spread over hours, an attacker who stays under the thresholds, and renames that carry only the new name.
    • Thresholds are heuristics tuned on synthetic traces, not fitted to this fleet. A low score does not mean a host is safe, and a high score is a lead, not proof.
    
      
    
      
    
      
    
        
        
        
        
      
    
      
    
      
    
        
    Host
    
        
    
      
    
      
    Detector status, thresholds and blind spots
    
      
    
    
    
    

    
    
    
      
    
        
    TTP similarity
    
        
    Which public profiles do these techniques resemble?
    
        
    Compare the techniques seen on a host, or a list you type, with summaries of public adversary reporting. The result is a prompt to hunt, never a conclusion about who is responsible.
    
      
    
      
    
        Similarity is not attribution (always applies)
        
    • A high score means the techniques resemble a public profile, not that the same actor is responsible.
    • Techniques are shared across many actors, and commodity techniques appear in most profiles, so overlap is weak evidence.
    • Profiles are incomplete summaries and may be stale.
